# 口播字幕工作台 · Jianying Subtitle Workbench

在自己的 Mac 上导入口播视频，确认预剪建议，调整字幕断句和局部重点，再生成可继续编辑的剪映草稿。

**当前是 v0.1 实验版，本地 Python 服务 + 浏览器界面。** 不是剪映内置插件，也不是双击即用的 `.app` 安装包。GitHub 提供源码和下载包；视频处理发生在下载者自己的电脑上，不是 GitHub 网页。

## 能做什么

- 导入 MP4 / MOV / MKV / WebM / M4V，生成逐字稿和词级时间戳。
- 检测长停顿、疑似语气词和相邻重复，提供原片试听和勾选确认。
- 根据确认区间生成预剪视频、原片区间映射及字幕。
- 连续逐字稿中点击字间拆分/合并，同步字幕列表。
- 拖选标重点、点击取消，支持单处样式、全局模板、常用颜色、撤销和重做。
- 保存项目 JSON，导出 SRT / ASS，生成 Mac 剪映原生草稿。
- 每个视频独立保存，下次启动可以继续编辑。

## 谁在识别、断句和标重点

| 环节 | 实现方式 | 需要人确认什么 |
| --- | --- | --- |
| 语音识别 | 本地 `mlx-whisper`，默认 `mlx-community/whisper-large-v3-turbo` | 错字、专有名词、口误 |
| 逐字时间 | Whisper 词级时间戳 + 词内插值 | 精细卡点时需核对 |
| 预剪建议 | FFmpeg 低音量检测、语气词和相邻重复规则 | 静音可能是自然停顿；语气词可能有表达作用 |
| 字幕断句 | 标点、停顿和目标字数规则 | 语义分组仍可人工拆合 |
| 重点 | 用户填写的关键词、数字及“关键/核心/注意”等提示词规则 | 是否确实值得强调 |
| 剪映草稿 | 按 Mac 11.6.0 原生 JSON 结构写入独立片段和文本样式 | 其他剪映版本需重新验证 |

**本版本没有接入通用大语言模型做语义审片。复杂改口、纠正、语义去重和语义重点尚未自动解决。** 语气词和重复建议默认不勾选；长停顿建议默认勾选，但所有删减都要点击确认才应用。不会自动改写或合成说话人的声音。

最早的单视频实验由本机 Whisper 转写，再由 Codex 结合上下文整理删减、纠错、断句与重点；这些人工判断没有被包装成通用 AI 能力。本仓库提供的是可独立运行的识别、规则建议和可视化编辑流程。

## 运行要求

- Apple Silicon Mac（M 系列），Python **3.11–3.12 推荐**。
- 系统已安装 FFmpeg（包含 ffprobe）。
- 可用浏览器；导出原生草稿还需安装 Mac 剪映专业版。
- **剪映适配基于 Mac 11.6.0**。原型已实际打开并显示视频切片、字幕和局部重点；改字、改样式、保存重开尚未完成全部实测。Windows、Intel Mac、CapCut 和其他版本未适配。
- 单个视频最长 2 小时、最大 10GB；转码和多份素材会占用磁盘空间。

## 第一次使用

1. 在本仓库点击 **Code → Download ZIP**，解压整个文件夹。也可 `git clone`。
2. 已有 Homebrew 的 Mac 可先安装运行环境：

   ```sh
   brew install python@3.12 ffmpeg
   ```

   Homebrew 安装说明见 [官方站点](https://brew.sh/)。
3. 双击 `安装依赖.command`。它会在文件夹中建立 `.venv` 并安装 Python 依赖；不安装系统级 Python 包。
4. 双击 `启动工作台.command`，浏览器会打开 `http://127.0.0.1:8766`。
5. 第一次识别需要从 Hugging Face 下载模型。下载成功后会使用本机缓存。

也可以完全在终端启动：

```sh
cd jianying-subtitle-workbench
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m workbench.launch
```

如果 `.command` 不能直接启动，可在该目录终端执行 `zsh 安装依赖.command` 或 `zsh 启动工作台.command`。

## 每次处理新视频

1. 双击 `启动工作台.command`，保持弹出的服务终端运行。
2. 首页选择新视频，可填写重点关键词、识别提示和每句目标字数。
3. 点击“导入并识别”，在本机等待处理。
4. 点击项目中的“确认预剪”，试听可疑区间，勾选要移除的内容。也可点击“全部保留”。
5. 点击“确认预剪，生成字幕工作台”，等待预览生成。
6. 打开字幕工作台，拆句/合句、校对文字、调整重点和颜色，点击“保存项目”。
7. **保存并退出剪映（⌘Q）**，再点击“导出到剪映”。剪映运行时会维护草稿索引，所以导出前必须退出。
8. 重新打开剪映，在首页打开提示中的同名新草稿，继续编辑。

无需分别向剪映导入 JSON 和 SRT。JSON 用于保存工作台编辑；SRT 不含重点样式；原生草稿包含独立视频片段和带局部样式的文本对象。

## 下次继续编辑

重新启动后，首页“本机项目”中打开已有项目即可。工作台修改会在浏览器暂存，**离开前请点“保存项目”写入磁盘**。

每次导出剪映都创建一个新工程。剪映内修改暂不回传工作台；工作台再次导出也不会更新已打开的剪映工程。

## 本地数据与配置

默认项目目录：

```text
~/Library/Application Support/JianyingSubtitleWorkbench/<项目ID>/
  input.json                 文件名与处理选项
  original.mp4               全长源视频（规范化转码，原上传文件另存）
  cleaned.mp4                按确认区间生成的预剪预览
  asr.json                   识别原始结果
  suggestions.json           预剪建议
  字幕项目_已修改.json        工作台项目
  剪映草稿/                  原生草稿备份
  backups/                   修改剪映索引前的备份
```

剪映使用的安装副本默认位于：

```text
~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/
```

复制 `local-config.example.json` 为 `.local-config.json` 可配置：

- `JSW_PORT`：服务端口，默认 8766。
- `JSW_WHISPER_MODEL`：Hugging Face 模型名称或已下载的 MLX Whisper 本地目录。
- `JSW_DATA_DIR`：项目保存目录。
- `JSW_DRAFT_ROOT`：自定义剪映草稿根目录。

也可使用同名环境变量。`.local-config.json` 被 Git 忽略，不会跟随源码提交。不要把视频、逐字稿、私人路径或密钥加入公开仓库。

## 隐私、费用与使用形式

服务只监听 `127.0.0.1`。浏览器导入的是本机文件，传到本机 Python 服务；没有上传视频到云端的代码。首次安装依赖及下载模型需要联网；已缓存模型后可离线处理。

本版本不调用付费模型 API，不需要 ChatGPT/Codex 订阅；正常识别、编辑和导出不产生 API token 费用。用户自行承担电脑运行、存储和网络成本。

别人下载到的是**同一个本地软件项目**，首次安装环境后在自己的 Mac 上运行，使用自己的素材和剪映。仓库不包含模型权重、剪映程序、剪映字体或作者的示例视频/逐字稿。

## 已验证与限制

- 已有自动检查：删减映射、字幕时间、UTF-16 字符区间、局部覆盖、视频分辨率、草稿引用、索引合并与不覆盖已有工程；字幕拆合、跨句重点、撤销、全局样式及 ASS 导出。
- 开发机使用已有本地模型完成 16 秒真实视频识别及预剪流程测试；模型首次在线下载及全新 Mac 安装仍需实机验证。
- 原型 Mac 11.6.0 打开与重点显示已验证；完整原生编辑往返和其他视频规格仍属实验适配。
- 仅处理单视频、单音轨的中文口播。逐字时间为估算；复杂语义删减仍需人工判断。
- 预剪预览经过转码；生成的剪映草稿引用全长规范化源视频的区间。原始上传文件保留在项目目录，外部原文件不修改。

运行检查：

```sh
python3 -m unittest discover -s tests -v
node tests/editor.test.cjs
```

测试不需要下载识别模型。原生编辑器未安装时，结构测试使用临时字体占位文件，不代表实际渲染验证。
